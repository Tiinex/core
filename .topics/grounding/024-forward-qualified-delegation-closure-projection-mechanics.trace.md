# Forward-Qualified Delegation Closure Projection Mechanics

## Objective

Implement the bounded Core projection needed for normal `ground` to recover the already-authorized qualified delegation closure from exact forward-selected current-work material instead of requiring equivalent delegation authority objects to be injected by a caller.

Consume the accepted Axiom delegation semantics without redefining them: Core qualifies and attributes existing Role/Task/Handoff/Decision/typed-Relation/source-authority declarations, exposes exact blockers when a link is missing, and reveals the normal Task -> Handoff -> carrier Tooling path only when the full chain is qualified.

## Done Criteria

- Resolve delegate/capability selection only from exact qualified current-work forward selectors and exact qualified Role capability material; cache/inventory/endpoint presence remains non-authoritative.
- Resolve delegation/process applicability only from explicit qualified current-scope authority under the accepted forward process-applicability rules; no reverse process/Relation discovery.
- Resolve target Workspace/repository and repo-local Task/Handoff placement only from explicit qualified authority; no repository/path inference from adjacency.
- Resolve Task/source creation or mutation authority only from exact upstream-qualified source authority; carriage/writability stays descriptive.
- Resolve return/reconciliation expectation from exact qualified current-work/Handoff authority without converting expectation into completion/acceptance.
- Every positive projection carries exact source-artifact path/digest/schema provenance and the forward selector basis.
- Normal `ground` against a correctly authored carrier reaches `delegationReadiness.state = qualified-for-delegation-authoring` without hidden caller/operator delegation JSON.
- Removing each individual claim yields the existing corresponding fail-closed blocker and no plain-chat/repository-scan fallback.
- Do not add new delegation/participant/process schema semantics, Role-name/path special cases, arbitrary prose parsing, global predicate keywords, or generated specialist work plans.
- Preserve blank/minimal Workspace + route-bounded cache behavior and canonical holder semantics.
- Full Core test suite, portable smoke and embedded bootstrap qualification remain green.
- Return exact qualification Evidence and one Loom -> Anchor Handoff.

## Scope

Core grounding/delegation projection and focused/adversarial regressions only. No Business/Docs mutation, no holder changes, no product work, no UI/receipt redesign and no unrelated refactor.
